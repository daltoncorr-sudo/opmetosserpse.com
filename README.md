# opmetosserpse.com

The studio site for Opmet Osserpse. A hand-kept static site: plain HTML, one stylesheet, one small script, no framework, no npm.

## How it works
- `content/site.json`: every word on the home page (the few lines after the cover and the words that link), the foundry holding page, Privacy and 404, plus the footer and clock.
- `content/projects/<slug>.json`: one file per project page. The page shows `title`, `lede`, the images of its daltoncorr.com page (`media` gives the alt text and size of the ones that were already here), the facts from `client`, `year`, `role` and `links`, and the end credits from `credits`. `deck` stays in the file for search descriptions; `challenge`, `work`, `system`, `deliverables` and `press` are the source of the notes, for press and later use.
- `content/notes/<slug>.json`: the new words for each project page, for D's approval: its opener, the "Work" fact, chapter labels, notes, photographers, how each film rests and plays, (Sunny's only) the items it hides, and, for a page that departs from its daltoncorr.com page on D's word, its own list of media, `media` (see "A project page"). Every word comes from the project's own file, except the alt text of pictures made for this site. `_review/` lists them all in one page.
- `content/pages/<slug>.json` and `content/pages/<slug>/`: finished pages, project pages D designed whole (Opmet Serif, Oct. 14). The build puts D's page inside the project frame every page has (the nameplate with Work and Home; at the end Work, Home and Back to top), and it slides down from home like the rest. The JSON holds the facts the lists and the data need (`title`, `client`, `year`, `lede`, `seo`, and `card`, the picture for the lists' preview and the share image). The folder holds what `python3 pages.py <slug> <D's page.html>` writes from D's file: `page.html` (the content, without D's own nameplate and end links), `page.css` (its styles, every rule inside `.os`, every class and id prefixed `os-`, so none meets the site's) and `page.js` (its script as `window.opmetPages[<slug>]`, which `site.js` runs on the page by itself and each time it slides in; served from `/js/pages/` with its own fingerprint), and its pictures, which go to `/media/<slug>/`. Its fonts are the site's (`site.css`): never embedded, never from another host (the Content-Security-Policy allows only the site's own). A finished page has its row in `work.json` like any project and keeps its own place there (`project_order` is for the template pages).
- `content/work.json`: the one list of every project (35), with `slug`, `title`, `year`, one or two `tags` from its controlled list, `selected` and `media` (empty for now). It drives Selected works, the Archive on the home page and `/projects/`; the build stops if it drifts from the project pages.
- `content/journal.json` and `content/journal/<slug>.txt`: the Journal (see "The Journal" below).
- `content/index.json`: `project_order`, the one list that sets the order of the projects on home and on `/projects/`. `home_order` is kept for now but unused.
- `static/`: CSS, JS, the fonts and the hand. `fonts/opmet-serif/` holds Opmet Serif 1.004, the studio's own face, as two variable WOFF2 files copied unchanged from `03_Type/opmet-serif/fonts/v1.004/` (`opmet-serif.woff2`, the upright, and `opmet-serif-italic.woff2`; weight 100 to 900, optical size 8 to 72). They are D's: served for the site only, never linked for download. `fonts/instrument-sans/` is Instrument Sans (SIL Open Font License, license included).
- `moves/`: the hand's moves on the cover, one folder each. `moves.py` loads them for the build, and `moves_lab.py` writes a workbench page, `_lab/hand.html`. See `moves/README.md`.
- `dc_source.py`: reads each project's page in the daltoncorr.com clone for its images, films and 3D and interactive pieces, in order, and brings those pieces' scripts (three.js r128 from `static/js/vendor/`, never a CDN), styles and files across.
- `build.py`: reads the content, pulls each image from a clone of the daltoncorr.com repo (`daltoncorr-sudo/daltoncorr-porfolio`), resizes it to WebP at 800, 1600 and 2400 px, writes each film as WebM and MP4 with a WebP poster frame (ffmpeg), and writes the finished site to `docs/`.
- `serve.py`: previews `docs/` the way GitHub Pages serves it.
- `check.py`: checks the build for broken links, placeholder text and house-style words, and the project pages for alt text, looping video (all but the two films D chose), cropped pictures, pictures that don't open in the lightbox, long notes, too many chapters, media order, project order and the way each page ends, and that Dalton's name appears only in credits.

## Build and preview
```bash
python3 -m pip install Pillow
brew install ffmpeg        # for video only
python3 build.py --daltoncorr ../_sources/daltoncorr-porfolio
python3 check.py
python3 serve.py            # http://127.0.0.1:8080/
```
The first build takes a few minutes, while it encodes about 400 images; later builds reuse them. Add `--zip` to also write a zip of each project's images for press.

## The rules of the look
The standard is a top agency, not a template. Image first. Very few words, only where needed. Extreme restraint, on project pages too.
- **The home page:** the hand and the name, alone in the center of the first screen. Below the scroll: a few short lines about the studio, then a plain list of the 22 projects. Nothing else.
- **No menu bar anywhere.** Inner pages carry only a stone coin and the name (Opmet Serif Bold, 20 to 24px, D, Oct. 15), small and centered as a pair, which link back to the cover. Project pages and the Journal carry the masthead instead (below).
- **Dalton Corr's name doesn't appear on the site,** except in a project's credits, as "Dalton Corr, Opmet Osserpse" (Sunny's Bookshop alone reads "Creative direction: Dalton Corr", with no photography credit: its notes file's `credits`, D, Oct. 13). The studio speaks for itself.
- An off-white ground (`--paper: #FBFBF8`), near-black ink, no accent color: the work brings every color.
- Two typefaces, Opmet Serif for names and Instrument Sans for the rest; two sizes; text at one weight, and the masthead in Opmet Serif Black, 900, the heaviest it has (D, Oct. 13, 2026). Project titles, their kicker and Journal article titles are large but regular, 400, and a project's role sits under its title, small, in the serif italic, in place of the Role fact (D, Oct. 20). The exception (D, Oct. 15): the cover's name and About's text are Opmet Serif regular, 400 (`--name-weight`). The optical size follows the type size (`font-optical-sizing: auto`), so titles get the Display drawing and text the Text drawing. Project pages are the exception: see below. The studio's name, Opmet Osserpse, is live text: on the cover in Opmet Serif regular, upright, at the size it had in Black, so narrower (D, Oct. 15; it was Black, 1.4 times as wide as the old wordmark, D, Oct. 13); in the inner pages' header in the upright Black too, 168 px wide; in the masthead in the upright Black, like the rest of the masthead. The controls use Opmet Serif Italic, for its weight axis (see "The controls"). Only buttons (the controls, and a film's Play links) are italic; nothing else is (D, Oct. 13).
- Plain lists of names: no years, dividers, numbers or boxes. No section headers. The case studies' names in the work lists (home and `/projects/`), the work list's label (Selected work, All work) and the press outlets on About are in Instrument Sans, regular (D, Oct. 13, 2026); the Journal's list keeps the serif.
- **A project page** sits on a 12-column grid (40 px page margins and 24 px gutters at 1440 px). On wider screens the opening (title, paragraph and facts) keeps its 1440 px width, so the paragraph and facts stay together under the title (D, Oct. 14). The title and credits are always at the top; any text that explains goes in the margins.
  - **The opening:** the masthead, the Journal's own component, as the studio's small nameplate: Opmet Osserpse alone (no coin, D, Oct. 15), in Opmet Serif Bold, small, the pair centered, linking to the cover (D, Oct. 13). Directly under it, Work, back to the work list the way the visitor left it, open or closed (D, Oct. 15; it was All work, which opened the full list), and Home beside it, back to the cover (D, Oct. 9). No Back. A line above the title, set like it, when a project has one ("20th Anniversary", from the notes file's `kicker`). The title, centered, large, in the bold serif: the focus of the page (`--pt`). Under it, the `lede` on the left (a narrow column, at most 22em, so it runs to more, shorter lines: D, Oct. 13) and one list on the right, each as wide as its words and centered as a pair under the title, so the opening keeps the title's axis however short the facts are (D, Oct. 14): the facts (client, year, work, role, link), then the credits, short: our credit under its first role ("Art direction: Dalton Corr, Opmet Osserpse"), partners who fabricated or produced something, and photography (left out until the photographers are known). Nothing else. No rules or lines.
  - **The work,** centered: every image, film, 3D model and interactive piece on the project's daltoncorr.com page, in that page's order (Sunny's Bookshop leaves out eight repeats). A page that departs from its daltoncorr.com page on D's word (HDtracks; Sunny's Bookshop, D's edit of it; HollyShorts Comedy 10, which opens with its animated poster and its printed poster side by side, the date announcement after them; Don't Let Them Out, without its second row of pictures and ending on its two poster tees, white then black, as cut-outs, work only and not for sale) lists its media in its notes file instead, `media`, in page order: each entry a picture or film (`src`, a path in the daltoncorr clone, or under `content/media/` for a file made for this site) or one of the daltoncorr.com page's 3D and interactive pieces (`piece`, as `w:badge-float`), with optional `alt`, `slot`, `gallery`, `row` and `cut` (build.py `notes_list`); `check.py` holds every page to the media order record, `_review/2026-10-19_media-order-record_v08.json` (v02, the daltoncorr.com orders of Oct. 8, stays as it was; v03 and v04 change only the pages D changed on purpose; v05 adds five new pages at their daltoncorr.com orders, Oct. 15; v06 gives Chop Suey Club, whose daltoncorr.com page has no pictures, its logo, from D; v07 has Sunny's Journal & Press marks in Vellum, for their Ink Navy panel, and v08 its announcement film beside the book drawn by hand, D, Oct. 19). Up to four chapters (Sunny's Bookshop, built after its Brand Bible, one per section, up to ten: D, Oct. 10) of 2 to 5 words each (only on projects with eight or more items); each label sits in the left margin beside its first block, on one line. Under 1100 px the margin is too narrow, so the labels are left out (Sunny's Bookshop, with plates, below: its labels sit just above each section at every width, D, Oct. 19). Text never shrinks a picture. Portrait pictures fill the eight middle columns; rows and landscape pictures always run across ten; full bleeds run edge to edge; 56 px apart. Under 1100 px (phones too), where the margins are too narrow for text, the notes and chapter labels are left out and pictures widen (rows and landscape pictures to the full width); a film's Play links stay. Pictures from one gallery on daltoncorr.com sit two to a row, at one height, 24 px apart, so a gallery reads as a group; a billboard, a film and a 3D piece each have their own row. In a notes file's list, entries that share a `row` sit in one row, side by side at one height, pictures and films alike, stacked on phones.
  - **Whole pictures:** nothing is ever cropped. A portrait picture or film, and a row, is never taller than about 85vh, centered in its columns, so a poster shows whole without scrolling. The one exception is a page capture meant to be scrolled, marked `"cap": false` in its notes file (HDtracks' home page, top to bottom). Every picture opens in the lightbox (below), the page's pictures one group; the 3D and interactive pieces and the films stay out.
  - **Cut-outs** (`cut` in a notes file's list): a transparent picture straight on the paper, no frame or box, at a size, `small`, `medium`, `large` or `xl` (at most 168, 272, 440 and 640 px wide). Cut-outs that share a `row` sit in it together, centered across the page, each at its own size, and wrap onto a second line on a narrow screen.
  - **True sizes:** `"cut": "true"` with `"w"`, the piece's width in points, shows pieces together at their real relative sizes, reduced (Sunny's stationery, as its Bible shows it).
  - **Air:** a notes file's `"air": true` gives its page twice the room between sections and more between rows within one (Sunny's Bookshop).
  - **Research** (Red Mask, D, Oct. 14): the notes file's `"research": true` and a label under each poster: its name and year, then why it belongs to that year and the five films studied for it, from D's Red Mask Production Art Tracker (April 2025). The posters keep their daltoncorr.com order and pairs (pairs stacked on phones).
  - **Labels** (`n`, `label` and `note` in a notes file's list, `note` one line or a list of lines; Sunny's Bookshop, after its Brand Bible, and Red Mask's research): under a picture, its numeral, a short name in the small sans and one short note under it in gray, all from the Bible's own words. Labeled cut-outs in a row stand on one baseline (`"align": "top"` hangs a row from one line instead, as the color swatches do; on a page with plates the pictures share one line and their labels the next, so a label that runs longer never lifts its picture). The numerals are the Bible's: an old-style serif figure (Opmet Serif Italic, its old-style figures) in the Bible's Gilt, #CBA65E. That Gilt is a deliberate exception to "no accent color", D's call for this page only (Oct. 10).
  - **Plates and panels** (Sunny's Bookshop only, D, Oct. 19: its notes file's `"plates": true`; `check.py` keeps both to this page): every row of cut-outs is a plate, its pictures on one line, each on its label's line (`"align": "top"` hangs a row from one line instead, as the color swatches do), and their labels level on the next, 12 px under the pictures. A plate row can take `"fit"` (`"area"`: each mark at one visual area; `"height"`: one height, times a mark's `"scale"`, so the two scripts are drawn at one size) and fills the plate; `"layout"`: `"shelf"` (the books, kept in one row on a phone), `"bento"` (the stationery: each piece in its box, its `"area"` in site.css `.cuts.bento`, filling it: the letterhead and event card two rows tall, the bookmark the whole height of the panel, the small pieces stacked beside them; on a phone two columns) or `"swatches"` (the colors: six columns, three, then two). Its cut-outs are trimmed to their ink at build, and a label's measures hold together ("16 to 40 mm", "24 pt"), so a line breaks only after a dot. Journal & Press's two marks stand on one baseline, wider apart (`"gap": 6`). Four chapters sit in rounded panels (a chapter's `"panel"`): the marks, the type and the stationery on one light off-white, #F3F0E9, a shade under the paper (`"light"`; D: "less dark, more like off white"), Journal & Press on the Bible's Ink Navy, in its Vellum marks. A panel runs to the photos' edges, has no border or shadow, holds cut-outs only, and its gray notes use the tag gray (Vellum notes on navy at 70%). Films, photographs, the delivery sheets, the studies and the palette itself stay on the paper. The announcement film sits beside the book drawn by hand, the two films on one row, even on a phone (`"stack": false`): the vertical film large, two fifths of the row, the book drawing centered beside it, each film's controls under it. The chapter labels show above every section at every width, and on a phone the delivery sheets and the studies sit two to a line (a chapter's `"phone": "pairs"`). These panels are a deliberate exception to "no boxes" and "no accent color", D's call for this page only (Oct. 19).
  - **No notes.** The pictures speak for themselves (D, Oct. 9, 2026). The notes files keep the field, empty, in case a note is ever needed; a film's Play links still show.
  - **At the end:** Work again, the same control, then Home (to the cover) and Back to top (D, Oct. 9). Back to top goes up to the page's top, in the panel on home or on the page by itself, the focus to the masthead. Never a next project.
  - The title large in the bold serif (`--pt`: up to 84 px, 30 px on phones); the 16 px opening paragraph and 13 px for the rest in Instrument Sans with its italic. Gray text is #6B665E.
  - Films show a poster frame, play once (muted) when on screen, and rest on a chosen frame, with "Play again" in the note. Every film plays muted, those with sound too (D, Oct. 10): a film with sound has Play with sound right under it (the shared control), which turns its sound on, from the start if it already rests, and becomes Mute. Reduced motion: nothing plays by itself. Nothing loops, except two films D chose (Oct. 10): Sunny's Bookshop's signature film, the script writing itself under the book, which opens its page (`content/media/sunnys-bookshop/sb-signature-script.mp4`, cut from the package's white logo film before its closing credit), and HollyShorts Comedy 10's animated poster (`hollyshorts-comedy-10-poster-popcorn.mp4`), `"loop": true` in their notes files. They play muted, round and round, while on screen; their poster is the first frame, or the frame `rest` names when the first is weak (the signature film rests on its finished script). A film drawn on white can have its white set to the paper when it's encoded and sit under the grain (`"grain": true`), so the drawing is on the page itself: Sunny's signature film and its book drawing. With reduced motion they wait for Play. `check.py` lets only those two loop. Pictures never move; the 3D models and interactive pieces move only as they do on daltoncorr.com.
- **Centered by the words** (D, Oct. 14): from 600 px up, left-aligned words in a centered column (the work list, open or closed, and a project's paragraph and facts) are moved sideways so the words themselves sit on the page's center line (site.js `opmetCenter`), never past their column; the work list glides as it opens and closes. Phones keep equal margins. Short pages (Privacy) are as wide as their lines; About, between 600 and 860 px, is one centered column.
- One motion value, 0.5 seconds, for fades and page changes. The one exception is the hand on the cover: after it arrives it waves, then plays one move about every 10 seconds, at random and never twice in a row, only while the cover is on screen: wave, spin, shrug, mirror, high five, a watch check, and thumbs up once its drawing exists. Each move has anticipation, overshoot and a settle. Reduced motion turns all of it off.
- **Hand moves:** each move is a folder in `moves/`, with its drawings in the same folder. See `moves/README.md`. The thumbs-up move waits for `moves/thumbs/thumbs-up.svg`.
- Copy: AP style, sentence case, no serial comma, the name as two words (*Opmet Osserpse*), espresso tempo in lowercase, no all caps, never "vibes," and never "AI" except inside a Journal article's body. Ordinals (22nd) are superscript everywhere: `build.py` writes them (`typo()`), so the content stays plain text.
- **About:** Home at the top left, the paragraphs in the first eight columns of a 12-column grid, the press from the ninth, set a little lower. The press has no heading on screen; each year sits in the left margin beside its first line, set like the work list's years (the small sans, gray), and under 1200 px, where that margin would reach the paragraphs, the list steps in to make room (D, Oct. 13).

## Hidden sections
`site.json` `"hidden"` lists sections kept off the site until they're built: now the Foundry and the Journal (D, Oct. 9). Nothing of a hidden section ships (D, Oct. 13): it is out of the cover menu and the text, its panel isn't on home, its pages (`foundry.html`, `journal/`) and pictures (`media/journal-<slug>/`) aren't built, and the build removes them from `docs/`. `/blog/` and any redirect in `content/redirects.json` that points into it go home instead. Its content stays in `content/`, and the shared stylesheet and script keep its rules. `check.py` checks all of this: no file, markup, words, link or redirect of a hidden section. To show one again, take it off the list and rebuild: its panel, pages, pictures and redirects come back.

## The machine-readable layer
For search engines, assistants and agents (`06_Visibility/`, W1): nothing of it shows on a page. `build.py` writes it from `content/`; `check.py` holds it to `content/` and to the house style.
- `content/entity.json`: the studio's shared facts (name, alternate name, the one-line description, the hand as logo, Venice, California, the email, Instagram, what the studio knows) and the crawlers `robots.txt` names, each with an `allow` switch (all on: D's answer 3). The long description is `site.json`'s `home.og_description`, the site's meta line.
- `site.json` `founder_in_data`: off. On, it puts D's name in the studio's data as its founder, and nowhere else (D's answer 2).
- **JSON-LD,** one block last in each page's head: the studio (`https://opmetosserpse.com/#studio`) and the site, on every page; a project page adds its work (for its client, with its pictures and their alt text) and its breadcrumb; `/projects/` adds the list of every project page. A hidden section has no pages, so none. The Content-Security-Policy leaves JSON-LD out: browsers never run it.
- `/data/studio.json` and `/data/work.json`: the same facts as plain JSON, public fields only (never a project's notes or credits); every page links them. `/llms.txt`: the name, the one line, the work and the address. The Journal's and the Foundry's data, feed and Article or Product data wait until they're shown.
- The sitemap dates each page by when its content last changed: its last commit, or today while a change isn't committed yet.

## The Journal
`/journal/` and `/journal/<slug>`: the studio's articles, as their own pages and as a panel above home (the cover menu's Journal, shown even before the first post; /journal/ stays out of the sitemap, and noindex, until a post is published). The masthead is Opmet, Osserpse, Journal in plain bold, half the big type on the list (D, Oct. 10), and small, like a project's nameplate, on an article, its lines left-justified on each other and the block centered (on project pages the same component is the small nameplate: the hand mark to the left of Opmet Osserpse, the pair centered), with the writing hand beside the last word (`static/brand/writing-hand.svg`, static: no animation for now; `[data-journal-hand]` and `[data-journal-word]` are kept as hooks, unused), then the line from `site.json`, in ink, centered. On an article, All articles and Home sit side by side under the masthead (D, Oct. 10). It is one component with the project pages' masthead (`build.py` `masthead()`). The list is centered like the work list; an article's text column is centered, its note margin to the right.
- **Posts:** `content/journal.json` lists them, newest first by `date` (ISO), with one or two tags from `tags` and `selected`. `"draft": true` keeps a post off the site (no page, no row, not in the sitemap); `python3 build.py --drafts` builds drafts for a local preview (never ship it). Only a draft may be undated or have an empty `.txt`.
- **Text:** `content/journal/<slug>.txt`, one paragraph per block, blocks separated by a blank line. Pictures live in `content/journal/images/<slug>/`. Two kinds of block are pictures, not text:
  - `image: <file> | <alt text> | <size> | <caption>`: size is `column` (the text's width, the default), `pair` (two pair lines in a row sit side by side, at one height) or `wide` (the whole column); the caption is optional. `image: <file> | <alt text>` still works.
  - `note: <file> | <what the note says> | <degrees>`: a handwritten note (a transparent PNG scan) in the margin beside the paragraph it follows, turned by the optional degrees (up to 15 either way). Under 1280 px, where the margin doesn't fit, it drops below its paragraph, a little smaller.
  - A `<file>` written `../<slug>/<file>` is a picture from another post's folder, built once, in that post's folder.
- **For now** all nine posts are live, dated 2026-10-10, each with the design checkpoint's sample: placeholder text and pictures, the pictures from the Venice post's folder (`../observations-from-venice-california/`). D's call, Oct. 10. Replace each `.txt` with its article (and its pictures) as it is written.
- The last paragraph ends on a tiny hand. "AI" and all caps are allowed only inside the article body.

## The controls
One system (`build.py` `ctl()`, `site.css` `.ctl`, `site.js` `opmetCtl` and `opmetFilters`); every control of a kind looks and behaves the same everywhere.
- **List labels** (Selected work, All work, Selected articles, All articles at the head of a list): `.work-label`, the serif. The work list's is for screen readers only, so its head shows just See more and Home (D, Oct. 13).
- **List toggles and links** (See more, See less, Home, Work, All articles, the cover's options, the Foundry's Home and Back): `.ctl`, Opmet Serif Italic at one size, in ink, no underline. Hover turns the word bold (700), in the one motion value, and nothing else (D, Oct. 15: it used to sweep with the cursor, wider toward the word's right); a hidden copy at the heaviest weight holds the width, so nothing moves. With reduced motion it turns bold at once. At least 44 px square to touch, without taking more room in its line; the focus ring shows for the keyboard.
- **Filters** (the Journal's topics; the Foundry's All, Digital and Physical, still at `#foundry?digital` and `#foundry?physical`): `.ctl.filter` in a `.filters` row, one script. Tag gray; the chosen one pure black and bold, with `aria-pressed`. The Journal's topics are set in the sans, upright, 14 px, like the tags they filter, with no weight sweep; the chosen one black in the sans's medium (D, Oct. 10).
- **Tags:** `.tags`, small sans, tag gray. Not clickable.

## The lightbox
One site component (site.js and site.css). Any `<img>` inside an element marked `data-lightbox` opens full size on the paper (a picture in one of Sunny's panels on that panel's ground, so its Vellum marks show; D, Oct. 19); that element's pictures are its group (a Journal article marks its body; a project page marks its `.pp`, so all of a project's pictures, cut-outs too, are one group). A click, Esc or the back button closes it; the arrow keys and a swipe step through the group; focus stays inside and returns to the picture. Fades only, instant with reduced motion. Pictures added later (an article or a project in the panel on home) work too. `data-lightbox-skip` on an `<img>`, or on an element around it, leaves it out (the Journal's handwritten notes; a project's 3D and interactive pieces, whose wrapper carries it); a picture inside a link stays a link. Films aren't pictures: they stay out. No frame, buttons or new color.

## Publishing
GitHub Pages, from the `docs/` folder on `main`. daltoncorr.com stays live as it is: both sites run side by side, with no redirects. `docs/CNAME` already says `opmetosserpse.com`. D publishes; nobody else pushes.
